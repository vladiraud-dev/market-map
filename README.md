# MarketMap — скринер для скальпинга

Карта рынка Binance, Bybit, OKX и Bitget (спот) с алертами на уровни, заливом открытого интереса и автопоиском сетапов.

**Открыть онлайн:** https://vladiraud-dev.github.io/market-map/

## Что умеет

- **Карта рынка** — самые интересные монеты сверху: движение за 5/15 минут и за сутки, всплеск объёма, размах. 3–24 графика, обновление каждые 10 секунд.
- **Биржи** — Binance, Bybit, OKX (фьючерсы и спот) и Bitget (спот). В «Споте» только монеты без фьючерсов.
- **Фильтры** — объём от любой суммы; акции/TradFi и стейблкоины скрыты.
- **Сетапы** — сайт сам размечает графики: уровни от непробитых хаёв/лоёв и наклонки. Поджатие, треугольник, тест и пробой наклонки, боковик, флаг, хай/лой дня, пробой, ложный пробой, ретест, нож.
- **Снимки** — картинка сетапа в момент появления; удаляется сама, когда сетап отработал или сломался.
- **Залив OI** — Binance, Bybit и OKX: колонка с сортировкой и уведомления.
- **Алерты** — уровни двойным кликом, звук, системные уведомления, Telegram.
- **Инструменты** — линейка (Shift + клик), рисование на графике, большой график со статистикой (объём, волатильность, NATR, сделки, корреляция с BTC).

## Как запустить у себя

Сайт — один файл `index.html`, ничего устанавливать не нужно: можно просто открыть его в браузере.

Если какая-то биржа не отдаёт данные странице, открытой как файл, запусти через локальный сервер (нужен [Node.js](https://nodejs.org)):

- Windows — `start.bat`
- Mac — `MarketMap.command`
- Mac/Linux — `./start.sh`

Сайт откроется на http://localhost:8080.

Подробная инструкция — в [README.txt](README.txt).
